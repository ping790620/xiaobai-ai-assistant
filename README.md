## 这是什么？

市面上的 AI（DeepSeek、豆包、通义千问……）很强，但对电脑小白来说门槛太高：
要注册、要实名、要找 API Key、要填配置、要选模型、要装进各种智能体客户端……

**小白AI管家把这些步骤拆成「点按钮、跟着图文做」的傻瓜流程**，
四大功能带你从零到真正用 AI 干活：

| 模块 | 能做什么 |
|------|----------|
| 🤖 **我要选 AI** | 对比 6 大主流平台价格，一键跳官方申请「钥匙」（API Key），附每一步图文 |
| 💡 **我不知道选哪个** | 告诉它你想做什么（聊天/写作/编程/翻译/做图/做视频），自动推荐合适平台与模型 |
| 📦 **AI 工具库** | 下载免费智能体软件（Cherry Studio、aider 等），全部官方下载链接，并给出「一键部署模型」按钮 |
| 📖 **实际案例** | 8 个真实场景手把手图文教程，截图就是真实对话界面，跟着做就能出成果 |

## 支持部署的智能体客户端

申请到 Key 后，配置页会按当前平台列出所有兼容的智能体，每个都有独立的「**部署模型**」按钮：

- **豆包工作 / 千问办公 / WorkBuddy / 百度搭子 DuMate**：一键下载安装，登录即用（自带官方模型，不需要 Key）
- **aider（终端编程）**：EXE 一键把 Key 写入环境变量；网页版可下载一键 `.bat` 脚本，双击即配好
- **OpenClaw（开源智能体）**：EXE 一键写入 `openclaw.json` 配置文件；网页版可下载配置文件手动放入
- **Hermes**：EXE 一键把 Key 写入 `~/.hermes/.env`、模型写入 `config.yaml`（DeepSeek/智谱/阿里/腾讯自动选官方提供商，其他平台走 OpenAI 兼容自定义）；网页版可下载部署文件
- **DeepSeek Harness**：EXE 一键把 Key 写入环境变量、模型和接口地址写入 `~/.dsh/settings.yaml`，配合一键安装启动；网页版可下载部署文件
- **官方网页版**：DeepSeek 官网、通义网页版、即梦、智谱体验中心等免 Key 入口

各平台的 API 地址、模型名由软件按平台自动生成，不用自己记参数。

## 🚀 快速上手

1. 下载并打开软件（网页版 / EXE 均可）。
2. 点首页「**我不知道选哪个**」，选择你要做的事 → 拿到平台推荐。

## ❓ 常见问题

**Key 是什么？** 一串 `sk-` 开头的字符，像开门的钥匙，填进智能体才能调用 AI。
生成后只显示一次，记得立刻复制保存。

**软件安全吗？会偷我的 Key / 骗钱吗？**
本软件是**纯静态网页，没有后端服务器**：不收一分钱、不中转 AI 服务；
你的 Key 只存在自己电脑浏览器/软件的本地存储里，不上传任何服务器；
所有「申请 / 下载」按钮都**直连平台官方页面**。不放心可随时清除本地数据彻底删除 Key。

**有免费额度吗？** 大部分平台新用户注册即送免费额度，智谱 GLM-4-Flash 完全免费，
日常聊天写作用很久。

**充值会不会乱扣费？** 按用量（字数）计费，用多少扣多少，各平台都有账单页，
不放心可在平台后台设置消费上限。

**手机能用吗？** 能，网页版已适配手机浏览器，申请 Key、配置在手机上都能完成。

**官方页面打不开？** 检查网络 → 换 Edge/Chrome 浏览器 → Ctrl+F5 强刷；
仍打不开可能是平台临时维护，稍后再试。

更多见应用内「帮助」页与[使用手册](docs/使用手册.md)。
