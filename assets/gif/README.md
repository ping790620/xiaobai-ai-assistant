# 演示 GIF 占位目录

本目录用于存放 README（GitHub 主页）引用的操作演示动图。

## 建议文件

| 文件名 | 演示内容 | 建议规格 |
|--------|----------|----------|
| `apply-key.gif` | 从平台官网申请并复制 API Key 的流程 | 宽 ≤ 1280px，时长 20–40 秒，文件 < 5MB |
| `deploy-agent.gif` | 点「部署模型」按钮，把 Key 一键配置进智能体（Cherry Studio / OpenClaw / aider） | 宽 ≤ 1280px，时长 20–40 秒，文件 < 5MB |
| `case-walkthrough.gif` | 进入案例 → 跟做步骤 → 点击图片放大 | 宽 ≤ 1280px，时长 20–40 秒，文件 < 5MB |

## 制作建议

- Windows 推荐用 ScreenToGif 录制并压缩；帧率 10–15fps 即可，体积小、清晰度够。
- 录制前统一把窗口调到 1280px 宽，保证 GitHub 上观感一致。
- 动图中不要出现真实 API Key、邮箱等隐私信息，演示时使用假 Key。
