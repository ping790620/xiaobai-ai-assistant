# 截图占位目录

本目录用于存放 README（GitHub 主页）引用的软件界面静态截图。

## 建议文件

| 文件名 | 内容 | 建议尺寸 |
|--------|------|----------|
| `hero.png` | 软件首页全貌（4 个入口卡片） | 1280 × 800 |
| `platforms.png` | 「我要选 AI」6 大平台对比页 | 1280 × 800 |
| `recommend.png` | 「我不知道选哪个」场景推荐页 | 1280 × 800 |
| `tools.png` | AI 工具库（智能体下载与部署按钮） | 1280 × 800 |
| `case-detail.png` | 案例详情（对话截图 + 点击放大效果） | 1280 × 800 |

## 制作方式

用 Edge 无头模式对运行中的页面截图，或直接在 EXE 窗口中截图（Alt + PrintScreen）。
截图放入本目录后，回到根目录 `README.md`，取消顶部图片注释并按需新增引用。

> 注意：真实 API Key 不要出现在任何截图里；截图前请使用假 Key（如 `sk-demo`）。
