## DeepSeek

**申请地址**：https://platform.deepseek.com/api_keys

1. **第一步：打开官方申请页**
   点击页面上的「打开官方申请页」按钮，会在新窗口打开 DeepSeek 平台。
   如果没有登录，会自动跳到登录页。
   截图：`assets/deepseek-signin-2026.png`
   说明：这是登录页，输入手机号收验证码。

2. **第二步：登录或注册账号**
   输入手机号，点击获取验证码，把收到的短信验证码填进去。
   第一次使用会自动注册，不用单独填资料。

3. **第三步：进入 API Keys 页面**
   登录成功后，页面左侧菜单找到「API Keys」点进去。
   如果已经在申请页，直接能看到创建按钮。

4. **第四步：创建新的 API Key**
   点击「Create new API Key」（创建新的密钥）按钮。
   给这个 Key 起个名字，比如「我的AI钥匙」，然后确认。

5. **第五步：复制生成的 Key**
   页面会弹出一串以「sk-」开头的字符，这就是你的 Key。
   ⚠️ 注意：这串字符只显示一次！一定要立刻复制保存好。
   点「Copy」按钮复制。

6. **第六步：回到本应用粘贴 Key**
   复制好之后，回到小白AI管家，点击「我已经拿到 Key 了，下一步」，
   把 Key 粘贴进去就行。

## 智谱GLM

**申请地址**：https://open.bigmodel.cn

1. **第一步：打开官方申请页**
   点击页面上的「打开官方申请页」按钮，新窗口打开智谱AI官网。
   截图：`assets/zhipu-home.png`
   说明：这是智谱AI首页，右上角点登录。

2. **第二步：登录或注册**
   点击右上角「登录」，弹出登录框。
   截图：`assets/zhipu-login-popup.png`
   说明：用手机号收验证码登录，第一次会自动注册。

3. **第三步：进入控制台**
   登录后，右上角点头像，选择「控制台」进入。
   控制台里能看到你账号的各种功能。

4. **第四步：找到 API Key 管理**
   在控制台左侧菜单找到「API Key 管理」点进去。
   这里可以看到你已有的 Key，也能创建新的。

5. **第五步：创建并复制 API Key**
   点击「添加 API Key」，起个名字，确认后会生成一串字符。
   ⚠️ 这串字符只显示一次，立刻点复制保存好。

6. **第六步：回到本应用粘贴 Key**
   复制好之后，回到小白AI管家，点击「我已经拿到 Key 了，下一步」，
   把 Key 粘贴进去就行。

## 火山方舟豆包

**申请地址**：https://console.volcengine.com/ark/region:cn-beijing/apiKey

1. **第一步：打开官方申请页**
   点击页面上的「打开官方申请页」按钮，新窗口打开火山方舟控制台。
   截图：`assets/volcark-home.png`
   说明：这是火山方舟首页，右上角点登录。

2. **第二步：登录火山引擎账号**
   点击右上角「登录」，弹出登录框。
   截图：`assets/volcark-login-popup.png`
   说明：用手机号收验证码登录。

3. **第三步：进入 API Key 页面**
   登录后会自动进入方舟控制台的 API Key 管理页。
   截图：`assets/volcark-apikey.png`
   说明：这里能看到 API Key 列表和创建按钮。

4. **第四步：创建 API Key**
   点击「创建 API Key」按钮，起个名字，确认创建。

5. **第五步：复制 Key**
   创建成功后会显示一串字符，⚠️ 只显示一次，立刻点复制保存好。

6. **第六步：回到本应用粘贴 Key**
   复制好之后，回到小白AI管家，点击「我已经拿到 Key 了，下一步」，
   把 Key 粘贴进去就行。
