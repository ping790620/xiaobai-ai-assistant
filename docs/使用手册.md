## 1. 软件简介

小白AI管家是帮零基础用户用好各大 AI 的引导工具，提供「选平台 → 申请 Key →
把模型部署进智能体 → 看案例跟做」一条龙图文指引。

- 软件本身**不提供 AI 模型、不收模型费用**；AI 服务由 DeepSeek、智谱、豆包、
  通义千问、文心一言、混元等官方平台提供并计费。
- 软件为**纯静态页面，没有后端服务器**，不收一分钱、不中转数据。
- 当前版本**完全免费、无需登录、无需激活码**。

## 2. 网页版的打开方式

网页版无需安装：

1. 下载本软件全部文件（保持文件夹结构完整）。
2. 双击文件夹里的 `index.html`，用 **Edge 或 Chrome** 浏览器打开即可。
3. 手机、Mac 也能用：把文件放到任意静态空间后用浏览器访问；手机浏览器已适配小屏幕。

> 桌面 EXE 的「一键部署 / 一键安装工具」等本地能力在网页版会自动变为
> 「下载配置文件 / 复制命令」的手动方式，效果相同。

## 3. Windows EXE 客户端安装

1. 从发布页（Releases）下载 `小白AI管家.exe`（约 46MB，**单文件免安装**）。
2. 双击运行，首次启动稍等几秒，无需安装向导。
3. 若弹出 **「Windows 已保护你的电脑」（SmartScreen 蓝色提示）**：
   点「**更多信息**」→ 再点「**仍要运行**」。
   这是因为软件暂未购买代码签名证书，**不是病毒、没有捆绑**。
4. 打开后即进入主界面，功能与网页版完全一致，并额外支持调用本机能力
   （一键写入配置、一键安装智能体、打开终端等）。

系统要求：**Windows 10 / 11（64 位）**。

## 5. 第一步：申请 API Key（钥匙）

1. 打开软件，点首页「**我要选 AI**」。
2. 浏览 6 大平台卡片与参考价格，拿不准就先点首页「**我不知道选哪个**」获取推荐
   （新手建议从**智谱 GLM-4-Flash（完全免费）**或**豆包工作（免 Key 软件）**入门）。
3. 选定平台后点「**去申请 Key**」，按图文步骤操作：
   打开官网 → 注册 / 登录 → 完成实名认证 → 进入 API Key 管理 → 创建 Key →
   **立刻复制保存**（Key 只显示一次，样子类似 `sk-xxxxxxxx`）。
4. 回到小白AI管家，进入「**已有 Key？去配置**」页面。
5. 在 Key 输入框中粘贴 Key：
   - **方法一（快捷键）**：鼠标点一下输入框，按 **Ctrl + V** 粘贴；
   - **方法二（粘贴按钮）**：点输入框旁边的「**📋 粘贴**」按钮，
     软件会自动读取系统剪贴板内容并填入（桌面版直接可用；
     浏览器若询问剪贴板权限，点「允许」即可）；
   - 也可以手动逐字输入。
6. 勾选要使用的模型，点「**生成配置**」，进入下一步部署。

> 输入框下方只显示脱敏信息，Key 仅保存在本机，不会上传。

## 6. 第二步：把模型部署到不同智能体

「智能体」是承载模型、让你实际对话干活的客户端软件。同一个 Key 可以部署到多个智能体。
在配置页粘好 Key、勾选模型、点「生成配置」后，下方「第三步」会按你选的平台列出所有兼容智能体，
每个智能体都有一张按钮卡片；点卡片就在下方展开它专属的部署步骤：

| 智能体 | 适合人群 | 点卡片后会发生什么 |
|--------|----------|--------------------|
| **豆包工作 / 千问办公 / WorkBuddy / 百度搭子 DuMate** | 完全不想碰 Key 的新手 | 自带官方模型：一键下载安装，登录账号即可使用，与你申请的 Key 无关 |
| **DeepSeek 官网 / 通义网页版 / 即梦等** | 不想装软件 | 直接打开官方网页，登录就能用，按账号免费点数或网页充值计费 |
| **aider（终端编程）** | 写代码、做 Excel 宏 | EXE 版一键把 Key 写入电脑环境变量；网页版可下载一键 `.bat` 脚本双击运行，并给出 Windows/Mac 终端命令 |
| **OpenClaw（开源智能体）** | 想接微信/Telegram、控制浏览器 | EXE 版一键安装官方脚本 + 一键写入 `openclaw.json`；网页版可下载配置文件手动放入 `.openclaw` 文件夹 |
| **Hermes（Nous 开源智能体）** | 想让 AI 有记忆、定时干活 | EXE 版一键把 Key 写入 `~/.hermes/.env`、模型与提供商写入 `config.yaml`：DeepSeek/智谱/阿里/腾讯自动对应官方提供商，其他平台走 OpenAI 兼容自定义；网页版可下载部署文件 |
| **DeepSeek Harness** | 进阶用户 | EXE 版一键把 Key 写入环境变量、模型与接口地址写入 `~/.dsh/settings.yaml`，再点一键安装以 `npx @deepseek-ai/dsh web` 启动；网页版可下载部署文件 |

各卡片都分两组显示：绿色「免 Key」角标的（装好登录就能用）和橙色「用 Key 部署」角标的
（需要你刚申请的 Key）。各平台 API 地址不同（例如 DeepSeek 为 `https://api.deepseek.com`、
阿里为 `dashscope.aliyuncs.com` 兼容地址），软件已按平台自动生成，不要混用，否则会报鉴权错误。

## 9. 隐私与 Key 安全

- Key 只保存在**你自己电脑**的浏览器本地存储（localStorage）或 EXE 本地数据中，
  软件**不收集、不上传、不中转**。
- 不要把 Key 发给任何人，不要贴到微信群、朋友圈、公开论坛、截图中。
- 怀疑泄露：立即登录对应平台后台，**删除旧 Key、重新生成**，再回软件更新。
- 想彻底清除本机 Key：删除浏览器站点数据；EXE 版可清除本地存储后删除程序。

## 10. 卸载

- **网页版**：直接删除软件文件夹、关闭网页即可；清除浏览器站点数据可一并删除本地 Key。
- **EXE 版**：删除 `小白AI管家.exe` 即可（单文件，无安装目录残留）。

## 11. 常见问题

**Q：Key 输入框不能粘贴怎么办？**
先点一下输入框再按 Ctrl+V；仍不行就用旁边的「📋 粘贴」按钮（确认剪贴板里刚复制过 Key）。
个别精简版浏览器禁用了网页读取剪贴板，此时改用 Windows EXE 版或手动输入。

**Q：收不到验证码？** 检查手机信号和「骚扰拦截 / 垃圾短信」，等 60 秒后重新获取，
不要连续狂点；仍不行换手机号或稍后再试。

**Q：实名认证是什么、要多久？** 国家规定正规 AI 平台都要做（身份证或刷脸），
验证你是真人，一般几分钟，最慢半天。

**Q：模型调用报 401 / 鉴权失败？** 多为 Key 填错、Key 与平台不匹配、API 地址混用。
请用软件生成的配置重新部署一次，确认 Key 前后没有多余空格。

**Q：会不会乱扣费？** 按用量计费、用多少扣多少，平台官网都有账单 / 消费记录页，
还可以设置消费上限。

**Q：官方页面打不开？** 检查网络 → 换 Edge/Chrome → 按 Ctrl+F5 强制刷新；
仍打不开可能是平台临时维护，过半小时再试。

**Q：手机能用吗？** 能，使用网页版，已适配手机浏览器。

**Q：SmartScreen 报安全警告？** 点「更多信息 → 仍要运行」，软件无病毒无捆绑。
